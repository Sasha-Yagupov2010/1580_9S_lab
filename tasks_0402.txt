'''
3 задача
инициализируем массив длинной 10. 
заполняем его случайными элементами в диапозоне от 1 до 50 включительно
выводим массив
инициализируем второй массив

проходим по элементам исходного массива
если позиция элемента четная, то записываем элемент, умноженный на 2, во второй массив
иначе записываем элемент, деленный целочисленно на 2 во второй массив

выводим второй массив
'''
from random import *
array = []
for i in range(10):
    array.append(randint(1,51))
    
print(*array)

array2 = []

for i in range(10):
    if i%2==0:
        array2.append(array[i]*2)
    else:
        array2.append(array[i]//2)
        
print(*array2)
